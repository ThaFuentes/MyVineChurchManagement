How the bot signs in

  1. POST /api/bot/login with Authorization: Bearer and the API key. That emails a 2FA key. It does not open a session.
  2. POST /api/bot/login/exchange with the same API key and header X-Bot-2FA. That returns a session for 1 hour.
  3. Send that session as Authorization: Bearer on every other call, including GET /api/bot/help.
