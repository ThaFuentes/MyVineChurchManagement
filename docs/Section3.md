# Section 3: The Spiritual Intelligence Modules

## Overview

The Spiritual Intelligence Modules are the private, sacred core of MyVineChurch.Online—tools designed to capture, preserve, and steward the supernatural life of the church.

These modules recognize that a healthy church is not only organized but Spirit-led. They provide structured ways to record, reflect on, and share (when appropriate) dreams, prophecies, prayer requests, and personal spiritual insights.

All content here respects the public/private visibility flag, allowing sensitive revelations to stay within the pastoral team while encouraging items can be shared with the broader body for edification.

## Key Modules

### 1. The Vault (Personal & Pastoral Spiritual Archive)
- A secure, searchable repository for spiritual insights.
- Entry types: Verse meditations, quotes, phrases, illustrations, testimonies.
- Visibility: Private (owner only) or Pastoral Group.
- Features:
  - Tagging for quick retrieval
  - Full-text search
  - Export options for personal use
- Use case: A pastor saves a powerful illustration or personal revelation during study—available instantly during sermon prep but never public unless chosen.

### 2. Dreams & Visions
- Dedicated space for recording and discussing dreams/visions.
- Features:
  - Submission form with title, date, description, optional scripture ties
  - Comment thread for interpretation/discernment
  - Visibility flag: Private, Pastoral Group, or Public
- Use case: A member has a significant dream → submits privately → pastoral team discusses → if edifying, marked public for community encouragement.

### 3. Prophecies
- Structured tracking of prophetic words spoken in the church.
- Features:
  - Submission with speaker, date, content, scripture reference
  - Comment thread for weighing/testing
  - Visibility flag: Private, Pastoral Group, or Public
- Use case: A prophecy given in service → recorded → leadership weighs → if confirmed, shared publicly for strengthening.

### 4. Prayer Engine
- Comprehensive prayer request management.
- Features:
  - Submission with title, details, optional anonymity
  - Visibility: Private (pastoral only), Pastoral Group, or Public
  - Response/comment thread ("I'm praying", testimonies of answered prayer)
  - Prayer count tracking
- Use case: Member submits sensitive request → stays private → pastoral team prays → testimony of answer shared publicly if desired.

## Design & UX Principles

- **Sensitivity First**: Default visibility is private. Public sharing is explicit choice.
- **Discernment Workflow**: Comment threads + visibility controls encourage weighing/testing before broader sharing.
- **Searchable**: All modules support full-text and tag search for quick retrieval during teaching/preaching.
- **Mobile-Friendly**: Submission from phone during/after service.
- **Audit Trail**: All submissions/edits logged for accountability.

## Integration with the Broader System

These modules feed directly into:
- Sermon Builder (pull from Vault for illustrations)
- Podium Mode (scripture/prayer references)
- Public Dashboard (public-flagged items appear for community encouragement)

They form the spiritual memory of the church—preserving what God is saying and doing, while protecting sensitivity.
